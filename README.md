# ChatBot

A simple chatbot project built as a learning project to understand how **APIs, backend services, and frontend applications** work together.

This was one of my early projects where I experimented with integrating an AI API and connecting it with a web interface.

## 🚀 Features

- Simple chatbot interface
- AI API integration
- Backend API handling
- Frontend and backend communication
- Environment variables for API keys

## 🛠️ Tech Stack

### Frontend
- React
- JavaScript
- CSS

### Backend
- Python
- API integration
